# API тренировок

Laravel API для Telegram Mini App, в котором клиент составляет недельное расписание тренировок, фиксирует выполнение выбранной программы и получает сравнение плана с фактом.

План программы хранится отдельно от тренировочной сессии: изменения расписания не переписывают уже начатую или завершённую тренировку.

## Анализ тренировок

После первого завершения всей тренировочной сессии автоматически создаётся анализ. В фоне рассчитываются отклонения по подходам, повторениям и объёму нагрузки на уровне тренировки, упражнений и порядковых пар подходов. После сравнения отдельная Job запрашивает заключение OpenAI по этой тренировке и доступной истории. После сохранения заключения третья Job отдельно генерирует рекомендации, проверяет основания и сохраняет допустимые предложения. Изменения применяются к программе только отдельным действием пользователя.

Авторизованный клиент получает статус и результат своей тренировки через:

Для конфигурации по умолчанию нужны PostgreSQL, Redis и постоянно работающий обработчик очереди:

```bash
php artisan queue:work redis --queue=workout-analysis --timeout=60
```
