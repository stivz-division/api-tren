# API тренировок

Laravel API для Telegram Mini App, в котором клиент составляет недельное расписание тренировок и фиксирует фактическое выполнение выбранной программы.

План программы хранится отдельно от тренировочной сессии: изменения расписания не переписывают уже начатую или завершённую тренировку.
