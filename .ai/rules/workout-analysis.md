# Workout Analysis

## Атомарный запуск анализа без outbox и обработки старой истории
При первом переходе WorkoutSession в Completed создавать анализ Pending синхронно в той же внешней транзакции и на том же соединении БД; ошибку инициализации не подавлять. После commit отправлять Job, а ошибку доставки оставлять для recovery. Без transactional outbox и границы по дате: recovery работает только с существующими Pending/Processing и никогда не создаёт анализ для отсутствующего. Повтор Failed доступен только служебной команде. В Redis округлять availableAt вверх до целой секунды, сохраняя микросекунды доменного scheduledAt.

## Первый запуск анализа без задержки
Первую попытку отправлять сразу после commit без delay. Задержки 5 и 30 секунд сохраняются для автоматических повторов; применять delay и округление времени вверх только если attemptNumber > 1 и availableAt ещё в будущем. Уже наступившие повторы отправлять немедленно.
